# 隐私政策

xl3.io 是一个开源项目的文档站点。这里没有账户、没有登录、没有表单——您输入的
任何内容都不会被收集或发送到任何地方。

## 我们统计什么

我们使用 [PostHog](https://posthog.com) 了解哪些文档页面被阅读，以便决定接下来
该写什么。具体记录哪些内容，取决于您在同意提示中所做的选择。

| | **接受** | **拒绝** |
| --- | --- | --- |
| 存储在您设备上的内容 | 一个用于识别浏览器的第一方 Cookie | 仅一条拒绝记录，以免重复询问 |
| 页面 URL、来源、语言 | 记录 | 记录 |
| 浏览器和操作系统 | 记录 | 记录 |
| 大致国家/地区 | 记录 | 无法获取 |
| 跨访问识别同一访客 | 是 | 否——每天生成新的标识符 |

拒绝并不会关闭统计，只是改变 PostHog 计数访问的方式。此时的标识符由 PostHog
服务器根据您的 IP 地址和浏览器信息，加上每天丢弃的随机值生成。不会有任何能够
识别您的内容写入您的设备，也无法通过该标识符追溯到您本人，或将其与前一天的
标识符重新关联。

我们不录制会话，不投放问卷，也从不为单个访客建立画像。本站没有广告，除 PostHog
之外没有任何第三方追踪器——不加载任何外部字体、脚本或 CDN 资源。

您在[浏览器转换工具](/try)中打开的文件完全在浏览器内处理，绝不会被上传。

## 由谁处理

PostHog 作为我们的数据处理者，在位于德国法兰克福的 **PostHog Cloud EU** 上进行
处理。分析数据保留在欧盟境内，不会传输至其他地区。IP 地址不会被存储。

## 法律依据

若您选择接受，依据为您的同意——GDPR 第 6 条第 1 款 (a) 项，以及针对 Cookie
本身的 ePrivacy 指令第 5 条第 3 款。

若您选择拒绝，设备上保留的只有该拒绝记录。这是为尊重您的拒绝所必需的，因此依据
第 5 条第 3 款无需另行取得同意。其余处理仅限于汇总层面的访客统计，依据是我们
了解哪些文档有用的正当利益——GDPR 第 6 条第 1 款 (f) 项。

## 更改您的选择

您可以随时改变主意。点击下方将清除已保存的选择，并重新显示同意提示：

<ConsentReset />

您也可以在浏览器设置中拦截或删除 Cookie。如果您的浏览器发送 Do Not Track 信号，
我们将视为拒绝，且不再询问。

## 托管

本站由 GitHub Pages 提供服务。GitHub 会处理包含 IP 地址在内的请求日志，用于交付
站点并防止滥用——参见
[GitHub 隐私声明](https://docs.github.com/zh/site-policy/privacy-policies/github-privacy-statement)。

## 联系方式

关于本页面的疑问，或访问、删除数据的请求，可通过
[github.com/xl3-lang/xl3/issues](https://github.com/xl3-lang/xl3/issues) 提出，
或发送至 `privacy@xl3.io`。
