# 개인정보처리방침

xl3.io는 오픈소스 프로젝트의 문서 사이트입니다. 계정도, 로그인도, 입력 양식도
없습니다. 입력하신 내용이 수집되거나 어딘가로 전송되는 일은 없습니다.

## 무엇을 측정하나

어떤 문서 페이지가 읽히는지 파악해 무엇을 더 쓸지 정하기 위해
[PostHog](https://posthog.com)를 사용합니다. 무엇이 기록되는지는 동의 안내에서
선택하신 내용에 따라 달라집니다.

| | **동의** | **거부** |
| --- | --- | --- |
| 기기에 저장되는 것 | 브라우저를 식별하는 자사 쿠키 | 다시 묻지 않기 위한 거부 기록 하나뿐 |
| 페이지 URL·유입 경로·언어 | 기록함 | 기록함 |
| 브라우저와 운영체제 | 기록함 | 기록함 |
| 대략적인 국가 | 기록함 | 확인 불가 |
| 재방문 시 동일인 인식 | 함 | 안 함 — 매일 새 식별자 |

거부해도 측정이 꺼지지는 않습니다. PostHog가 방문을 집계하는 방식이 바뀔
뿐입니다. 이때 식별자는 IP 주소와 브라우저 정보에 매일 폐기되는 임의값을 섞어
PostHog 서버에서 생성됩니다. 귀하를 식별하는 값은 기기에 기록되지 않고, 이
식별자로 귀하를 역추적하거나 어제의 식별자와 다시 연결할 수 없습니다.

세션을 녹화하지 않고, 설문을 띄우지 않으며, 개별 방문자의 프로필을 만들지
않습니다. 이 사이트에는 광고가 없고 PostHog 외의 서드파티 추적기도 없습니다 —
외부 폰트·스크립트·CDN 자산을 전혀 불러오지 않습니다.

[브라우저 변환기](/try)에서 여는 파일은 전부 브라우저 안에서 처리됩니다.
업로드되지 않습니다.

## 누가 처리하나

PostHog가 수탁 처리자로서 독일 프랑크푸르트에 있는 **PostHog Cloud EU**에서
처리합니다. 분석 데이터는 EU 역내에 머무르며 다른 곳으로 이전되지 않습니다. IP
주소는 저장되지 않습니다.

## 법적 근거

동의하신 경우의 근거는 귀하의 동의입니다 — GDPR 제6조 제1항 (a)호, 그리고
쿠키 자체에 대해서는 ePrivacy 지침 제5조 제3항.

거부하신 경우 기기에 남는 것은 그 거부 기록뿐이며, 이는 거부 의사를 지키기 위해
반드시 필요한 것이므로 제5조 제3항에 따른 별도의 동의를 요하지 않습니다. 나머지
처리는 집계 단위의 방문자 측정에 한정되며, 어떤 문서가 유용한지 파악하려는
정당한 이익에 근거합니다 — GDPR 제6조 제1항 (f)호.

## 선택 바꾸기

언제든지 마음을 바꾸실 수 있습니다. 아래를 누르면 저장된 선택이 지워지고 동의
안내가 다시 표시됩니다.

<ConsentReset />

브라우저 설정에서 쿠키를 차단하거나 삭제하셔도 됩니다. 브라우저가 Do Not Track
신호를 보내는 경우에는 거부로 간주하며 묻지 않습니다.

## 호스팅

이 사이트는 GitHub Pages가 제공합니다. GitHub은 사이트를 전달하고 오·남용을
방지하기 위해 IP 주소를 포함한 요청 로그를 처리합니다 —
[GitHub 개인정보 보호 정책](https://docs.github.com/ko/site-policy/privacy-policies/github-privacy-statement)을
참고하십시오.
