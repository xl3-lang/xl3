# プライバシー

xl3.io はオープンソースプロジェクトのドキュメントサイトです。アカウントも
ログインも入力フォームもありません。入力された内容が収集されたり、どこかへ
送信されたりすることはありません。

## 何を計測しているか

どのドキュメントページが読まれているかを把握し、次に何を書くべきか判断するために
[PostHog](https://posthog.com) を使用しています。記録される内容は、同意の案内で
選択された内容によって異なります。

| | **同意する** | **拒否する** |
| --- | --- | --- |
| 端末に保存されるもの | ブラウザを識別するファーストパーティ Cookie | 再度お尋ねしないための拒否の記録のみ |
| ページ URL・参照元・言語 | 記録する | 記録する |
| ブラウザと OS | 記録する | 記録する |
| おおよその国 | 記録する | 取得しない |
| 再訪問時の同一人物の判別 | する | しない — 毎日新しい識別子 |

拒否しても計測が止まるわけではありません。PostHog が訪問を数える方法が変わる
だけです。この場合の識別子は、IP アドレスとブラウザ情報に毎日破棄されるランダム値を
加えて PostHog のサーバー側で生成されます。お使いの端末にはあなたを識別する値は
書き込まれず、この識別子からあなたを辿ることも、昨日の識別子と結び付けることも
できません。

セッションの録画は行わず、アンケートも表示せず、個々の訪問者のプロファイルを
作成することもありません。このサイトに広告はなく、PostHog 以外のサードパーティ
トラッカーもありません。外部のフォント・スクリプト・CDN アセットは一切
読み込みません。

[ブラウザ変換ツール](/try) で開いたファイルは、すべてブラウザ内で処理されます。
アップロードされることはありません。

## 誰が処理しているか

PostHog が処理者として、ドイツ・フランクフルトの **PostHog Cloud EU** で処理して
います。分析データは EU 域内に留まり、域外へ移転されることはありません。IP
アドレスは保存されません。

## 法的根拠

同意された場合の根拠はあなたの同意です — GDPR 第6条第1項(a)、および Cookie
そのものについては ePrivacy 指令第5条第3項。

拒否された場合、端末に残るのはその拒否の記録だけです。これは拒否の意思を守る
ために厳密に必要なものであり、第5条第3項に基づく個別の同意を要しません。残りの
処理は集計単位での訪問者計測に限られ、どのドキュメントが役立っているかを把握する
という正当な利益に基づいています — GDPR 第6条第1項(f)。

## 選択の変更

いつでも変更できます。以下を押すと保存された選択が消去され、同意の案内が再び
表示されます。

ブラウザの設定で Cookie をブロックまたは削除することもできます。ブラウザが
Do Not Track シグナルを送信している場合は、拒否とみなしお尋ねしません。
